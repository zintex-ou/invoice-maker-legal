# Invoice Maker — legal & support pages

Static GitHub Pages site for Invoice & Receipt Maker: Smart (iOS, bundle `com.make.your.invoice`), published by Zintex OÜ.

- `index.html` — support page + FAQ (use as **Support URL**)
- `privacy.html` — privacy policy (use as **Privacy Policy URL**)
- `terms.html` — terms of use (linked from the app's paywall/settings)

Enable Pages: repo **Settings → Pages → Deploy from branch → main / (root)**.
